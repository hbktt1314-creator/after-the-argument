# after-the-argument

发生矛盾后的一些体会，找个地方记录下来，也希望给看到的人一些情感共鸣与安慰。

记录冲突后的感受、需求与修复尝试

不要幻想从别人那里得到安慰与理解，靠自己；

会赚钱不会照顾家里的日常细节，被说不理解老婆，不懂她；全心照顾家里日常，不会赚钱，被说无能；赚的少还不会照顾家里日常，那是无能又不爱老婆；

做好十件事抵不过做坏一件事，哪怕做好99件事也是如此，人是不知足的，不要善良；

让偏见长在别人心里，不要长在自己心里，庸人自扰之；

不要被感觉欺骗，多次感觉是对的，这不但增强“感觉”的信心还会陷入虚空索敌的陷阱；

不拿别人的过错惩罚自己，最好对方能继续错下去；

责怪，贬低别人不会让自己过的好，更不会提升自己；

心胸宽广些会自动过滤很多内耗；

觉得自己可怜，委屈，不但不会得到同情与帮助，那只会让看起来更可怜；

用感情，不用大脑思考，这愚蠢的，任何事情都是如此；

不要和女人讲道理，也不要以不良的目的去和她们相处，虽然油嘴滑舌，哄骗可以让女人开心，甚至死心踏地，那不是我想要的；
